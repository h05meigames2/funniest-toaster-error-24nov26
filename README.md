## What it does

`main.py` (Python stdlib only) writes a single line — the error message a
kitchen toaster shows its owner when something goes wrong — to
`/output/entry.txt`:

> TOASTING ABORTED: YOUR BREAD HAS UNIONISED AND DEMANDS BUTTER UP FRONT.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
